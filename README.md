# 이클립스 강화 수익 계산기

거래소 강화 장사의 기대 비용·순익·리스크를 여러 아이템에 대해 한 번에 비교하는 단일 HTML 계산기입니다.

- 확률 출처: https://eclipse.onstove.com/ko/probability?menu=004.003 (2026-10-04 기준)

모든 결과는 기대값이며 실제 결과는 크게 흔들릴 수 있습니다.
